## Entry

> Approved; the fallback is documented, which will be a comfort to whoever finds us.

82 characters, single line, within the 140-character limit.

## How it works

Run `main.py` and it writes the entry text verbatim to `/output/entry.txt` (UTF-8, no trailing newline), then reads the file back and verifies it matches the entry exactly, exiting with an error if it does not.
